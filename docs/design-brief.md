# Fuel Atlas 本版设计约束

日期：2026-11-04。将用户参考流程转成以下六项可执行约束，用于限制实现和验收。

## 1. 范围：围绕一次加油决策

主任务是东亚短途宽体机既定轮转的各站加油量优化。支持 2–5 个连续航段，默认 PVG → ICN → HND → PVG。先展示可操作方案，再提供报价来源和方法；原油市与供应链工作台保留在 `network.html`。本版不新增绕飞/经停优化、预测系统、账户、订单或未接通的实时报价服务。

## 2. 层级：地图与结果先于复杂参数

首屏依次呈现品牌/导航、短标题与产品问题、轮转模式条、东亚地图及侧边决策卡。下一层是轮转编辑表、逐段方案卡，再下层是机场供油表和来源。性能、保留油与重量参数放在可展开区域。节省金额、比较基线、建议站点和额外耗油同时可见，不能只突出脱离条件的收益数。

## 3. 视觉：用航空产品语言转译参考

采用深墨蓝背景、分层面板、细边框、雾白文字和浅绿色行动/燃油强调色；标题结合 Manrope 与 Instrument Serif 斜体，本地提供字体和许可。英文编辑式标题与中文操作说明分工，数字稳定对齐。地理轮廓、机场节点、弧形航路和示意比例尺承担主体视觉。

**不照搬植物、岩石或与航空无关的装饰物。** 将参考中的视觉张力转译为“飞机沿路径移动、当前航段高亮、燃油与采购数值变化”的产品动作。动画服务于解释加油方案，不能遮挡输入、冒充实时航迹或让用户无法读数。

## 4. 核心交互：每个动作对应决策反馈

编辑轮转后立即将旧结果标为待计算，清除旧建议并禁用播放/导出；重新计算后更新地图与方案。方案切换展示优化与按需两种相同终点库存策略；播放沿选中方案的固定路径逐段运动，可停止。机场支持指针和键盘查看价格状态，供油表支持城市/代码搜索与地区筛选。

示例场景与用户报价用明确模式切换分开。CSV 导入显示逐行问题，缺失/过期报价保持缺失；导出带上输入、价格模式和来源。错误、不可行、报价待补齐与加载失败均给明确状态，不用占位收益掩盖问题。

## 5. 技术栈：静态可部署、计算可复核

使用 HTML、CSS、原生 JavaScript ES modules、SVG 与浏览器 `requestAnimationFrame`；报价使用原生文件读取和本地内存处理。新轮转模型为独立纯函数模块，CSV 校验为独立模块，来源目录为 JSON。保留项目现有 Node/esbuild 构建测试流程；原供应链模型继续使用已打包 LP 求解器。新增首页不依赖收费地图、服务器求解或前端密钥。

## 6. 验收：操作、数据语义与可访问性

- 桌面地图与决策卡并列，小屏纵向排列；表格可横向滚动，主要操作不被裁切。
- 默认示例可复算；同价或价差不足时不凭空推荐提前携油。
- 增删或修改航段后保持连续性，2–5 段边界有效；油箱、重量、保留油或供油超限时显示诊断。
- 优化/按需切换与播放使用相应方案；编辑后不继续播放旧结果。
- 示例价始终标为示例；用户报价须通过 CSV 口径与有效期校验，缺失值不能回退示例价。
- 同初始、同终点燃油比较；基线不可行时不显示节省比例。
- 键盘焦点清楚，表单有标签，反馈有状态/警报语义；减少动态效果偏好禁用装饰动画并大幅缩短航线播放。
- 来源卡片可打开真实来源且说明访问限制；油市基准、挂牌与到机报价不混用。
- 模型、报价解析及原回归测试通过；视觉检查和浏览器验证单独如实记录，不用构建成功代替。
