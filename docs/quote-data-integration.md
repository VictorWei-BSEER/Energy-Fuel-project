# 报价数据接入与计划日期

采用供应商授权报价 CSV 作为优化输入。航司从已有合同价格通知、正式报价或获授权的客户门户取得价格，核对适用航班、费用和有效期后，转换为下列八列，再通过页面的报价导入功能使用。

## CSV 字段映射

```csv
airport,supplier,price_usd_per_t,valid_from,valid_until,delivery_basis,fees_included,source
```

| 字段 | 填写规则 |
| --- | --- |
| `airport` | 页面支持的 17 个东亚机场之一，大写 IATA 三字码。 |
| `supplier` | 报价供应商名称。 |
| `price_usd_per_t` | 已换算为 USD/公吨的正数，包含适用的燃油、加注、运输、储存及税费。 |
| `valid_from` | 供应商确认的首个有效日，格式 `YYYY-MM-DD`。 |
| `valid_until` | 供应商确认的最后有效日，格式 `YYYY-MM-DD`。 |
| `delivery_basis` | 固定为 `into-plane`。 |
| `fees_included` | 确认费用完整后填写 `true`。 |
| `source` | 原始报价文档名称及合同/报价编号，或不含登录凭据的 HTTP(S) 来源链接。 |

原币种、原单位、汇率日期、密度及温度依据保留在原始报价或换算记录中，由 `source` 对应。体积报价转换为质量报价时使用合同或实测密度；原始文件缺少费用或有效期时，先补齐后导入。页面接受已经完成核对和换算的 CSV。

文件采用 UTF-8，最大 256 KiB、500 条记录；八列可调整顺序，表头须完整且无重复或额外字段。价格须为有限正数，日期须真实存在且起止顺序正确。供应商和来源须非空；公式开头文本、危险链接及不符合 CSV 语法的内容会被拒绝。导入反馈列出未接受记录的原因。

## 日期与报价匹配

- 首次打开页面时，空的计划日期按浏览器本地日历初始化为当天。明确选择的未来日期保留。
- 整个轮转使用同一个计划日期 `planDate`；CSV 导入校验、机场报价匹配、优化计算和方案导出均使用这个日期。本次模型使用轮转级日期。
- 有效期包含首尾两日：`valid_from <= planDate <= valid_until`。日期作为日历字符串比较，避免 UTC 换算造成前后偏移一天。
- CSV 保留历史和未来生效记录。改变计划日期后，按新日期重新匹配报价。
- 同一机场有效期重叠的记录全部排除，待用户先选定适用合同。每个出发机场须有唯一适用报价；缺失或已过期时显示待报价，并阻止使用该报价计算。
- 下载模板按所选计划日期生成日期提示；供应商、价格、来源及最终有效期依据实际报价填写。
- 修改计划日期使已有计算失效。重新计算后，导出使用该次求解的日期与报价来源快照，保留价格、供应商、来源及有效期。

## 端到端操作与验收

1. 选择计划日期，下载报价模板。核对模板日期与页面一致。
2. 按上述字段填写覆盖轮转各出发机场的报价，导入 CSV，查看接受条数和逐行错误。
3. 切换至“我的报价”，确认各机场价格和来源，执行优化。
4. 导出方案 JSON，核对 `date`、各航段输入价格和报价来源/有效期，与刚完成的计算一致。
5. 将计划日期移至某报价结束日之后。该报价须失效，旧方案不能继续导出；补齐适用报价后再计算。
6. 选择未来日期，导入覆盖该日的报价。未来报价须可用于该计划，导入和计算不得将日期改回今天。
7. 在本地午夜前后、UTC 与本地日期不同的时区，以及月末、年末和闰日，验证首次默认日期和有效期首尾边界。

自动化回归使用明确标记的合成报价验证以上流程。测试价格用于复现和断言；真实业务数据由供应商文件提供。当前交付完成 CSV 接入、日期一致性和导出链路；接入真实合同价格所需的报价文件或客户账户尚未提供。

## 已核验的数据渠道

以下官方资料访问日期为 **2026-11-04**。

| 渠道 | 接入用途 |
| --- | --- |
| [World Fuel Contract / myWorld](https://www.worldfuel.com/aviation/fuel-and-card-programs/world-fuel-contract-fuel/) | 客户合同报价与多机场比较。获授权的客户可将适用报价整理为上述 CSV；API 接入需供应商提供接口和授权。 |
| [Airportdata Level 4 API](https://api.airportdata.com/technical-specifications/details-levels-3-4) | 文档提供 `GET /fuel_prices/{handler_id}`，含燃油价格、币种、体积单位和更新时间。接入前需补齐目标机场覆盖、合同适用性、费用及有效期。 |
| [台湾中油航空燃油价格表](https://vipmbr.cpc.com.tw/mbwebs/showlistprice_d1510_en.aspx) | 公开挂牌参考。页面列明 TPE 运输、储存费用另收；完整到机报价仍需供应商确认。 |
| [IATA Fuel Data Standards](https://www.iata.org/en/programs/ops-infra/fuel/data-standards/) | 后续供应商数据交换可映射 Tender/Bid、Operational、Transaction、Invoice 标准。 |

需要账户的渠道由供应商授权接入。密钥放在后续服务端连接器中；当前静态页面通过用户上传 CSV 获取报价。公开挂牌和市场基准保持其原有参考口径。
