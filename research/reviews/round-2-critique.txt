TARGETED REVISIONS

R2-01 [P1] Explicitly separate the feasible price-comparison world from the shortage world.
The matched accounting counterfactual is correct when both purchase locations can supply the same useful fuel. During an actual destination interruption, buying the comparison tonne there may be impossible. The normal-operation break-even price is therefore not a dispatch decision rule or a valuation of avoiding cancellation during a shortage.
Acceptance: add this distinction to the methods/report and near any UI displaying threshold and shortfall figures together. Define the shortage output as conditional fuel displacement given origin availability/headroom. Do not imply that the model monetizes the value of keeping a flight operating.

R2-02 [P1] Make the gross-origin versus net-destination denominator impossible to miss.
The code correctly separates these bases, but one headline is 0.5144tCO2 per net tonne delivered while the local-interruption case is 0.4424tCO2 per gross tonne loaded. A presentation could accidentally combine them.
Acceptance: provide a compact paired example or explicitly labelled figure showing both bases. Add localAdditionalBurnT and localAdditionalCo2T to the machine-readable CSV so the shortfall case can be audited without reconstructing omitted quantities. Rebuild results after this schema addition; these changes should not alter existing numerical values.

R2-03 [P1] Close the frozen-version provenance gap.
The code changed between the initial hash manifest and review. The change is benign and documented above, but a professional reproducibility claim requires a matching final code/input/output set.
Acceptance: retain the original manifest as the submitted Round 2 snapshot, record the finite-output-guard change, and create a reviewed/revised manifest covering the actual code, outputs and tests used for the next round. Do not overwrite the historical evidence of the sequence.

REPORTING ADVICE FOR ROUND 3 (not new numerical defects)
- Make the controlled-duration example the main identified finding. Route examples should be clearly secondary geographic illustrations rather than airport recommendations.
- The carbon illustration depends on c/pA; the zero-carbon/zero-fee ratio does not depend on the arbitrary USD1,000/t normalization. Keep this distinction next to monetary illustrations.
- Zero additional handling/payload opportunity cost is a lower-cost scenario, not an empirical estimate. The formula shows that each additional f/pA shifts the required ratio upward.
- The 486-case envelope is a finite sensitivity grid, not a confidence interval or probability distribution. The linear model is more fuel-intensive only relative to the specified exponential comparator; this is not proof that it bounds real aircraft performance.
- A shared fuel quota accounting identity establishes additional fuel consumption, not a universally negative security outcome: scarce fuel may still be more useful in one place than another. Qualify any regional policy claim accordingly.
